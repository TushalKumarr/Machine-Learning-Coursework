# Sukkur IBA University - Machine Learning Coursework 🤖

This repository houses the coursework, lab files, and lecture tracking for the **Machine Learning** course at **Sukkur IBA University**. 

## 🏫 Academic Context
* **Institution:** Sukkur IBA University [Sukkur IBA University](https://www.iba-suk.edu.pk/)
* **Department:** Computer Science / Software Engineering
* **Environment:** Python (Jupyter Notebooks)

## 🗂️ Repository Outline
* `/lectures`: Lecture slides, core algorithms, and concept notes.
* `/labs`: Weekly Python implementations covering data analysis and modeling.
* `/final-project`: Dedicated workspace for the end-of-semester ML application.

## 🛠️ Required Packages
To set up your local development environment matching the lab specifications, run:
```bash
pip install numpy pandas scikit-learn matplotlib jupyter
```
